# SAANS Production Setup Guide

## Phase 1: Railway Backend Configuration ⚠️ CRITICAL

### Step 1.1: Add PostgreSQL Database to Railway

1. Go to **Railway Dashboard** → Select **SAANS project**
2. Click **"Create"** button (top right)
3. Select **"PostgreSQL"** from the services list
4. Wait for the database to be created (2-3 minutes)
5. Railway will automatically add `DATABASE_URL` to environment variables

### Step 1.2: Verify Environment Variables

In Railway Dashboard → SAANS Project → Variables:

Check these variables exist:
- ✅ `DATABASE_URL` (auto-generated by PostgreSQL)
- ✅ `NODE_ENV` = `production`
- ✅ `API_PORT` = `3000`
- ✅ `API_HOST` = `0.0.0.0`

**Required additions** (if missing):
```
CORS_ORIGIN=https://saans-7x00v3qnz-chetanya-s-projects.vercel.app
JWT_SECRET=<change-this-to-something-random-and-secure>
JWT_REFRESH_SECRET=<change-this-to-something-random-and-secure>
LOG_LEVEL=info
```

### Step 1.3: Trigger Redeploy

1. Railway Dashboard → SAANS Project → Build & Deploy
2. Click **"Redeploy Latest"**
3. Wait for deployment to complete (check logs)
4. Test: `curl https://saans-production-023e.up.railway.app/health`
   - Should return: `{"status":"ok",...}` with status 200

## Phase 2: Database Migrations 📊

### Step 2.1: Run Prisma Migrations (LOCAL)

Once Railway database is connected:

```bash
cd saans-api

# Set production database URL temporarily
export DATABASE_URL="<copy-from-railway-dashboard>"

# Run migrations
npx prisma migrate deploy

# Verify schema
npx prisma db push

# Check tables
npx prisma db execute --stdin < prisma/seed.sql

unset DATABASE_URL
```

### Step 2.2: Verify Database Connection

```bash

# List current tables
```

## Phase 3: Seed Initial Data 🌱

### Step 3.1: Add Therapist Data

Create `saans-api/prisma/seed-therapists.ts`:

```typescript
import { PrismaClient } from "@prisma/client";

const prisma = new PrismaClient();

async function seedTherapists() {
  const therapists = [
    {
      name: "Dr. Rajesh Kumar",
      email: "rajesh.kumar@saans.app",
      specialization: "Depression & Anxiety",
      city: "Mumbai",
      experience: 10,
      rating: 4.8,
      languages: ["English", "Hindi", "Marathi"],
    },
    {
      name: "Dr. Priya Singh",
      email: "priya.singh@saans.app",
      specialization: "Relationship Counseling",
      city: "Delhi",
      experience: 8,
      rating: 4.9,
      languages: ["English", "Hindi"],
    },
    {
      name: "Dr. Amit Patel",
      email: "amit.patel@saans.app",
      specialization: "Stress Management",
      city: "Bangalore",
      experience: 12,
      rating: 4.7,
      languages: ["English", "Gujarati", "Hindi"],
    },
  ];

  for (const therapist of therapists) {
    await prisma.therapist.upsert({
      where: { email: therapist.email },
      update: therapist,
      create: {
        ...therapist,
        role: "THERAPIST",
      },
    });
  }

  console.log("✅ Therapists seeded successfully");
}

seedTherapists()
  .then(async () => await prisma.$disconnect())
  .catch(async (e) => {
    console.error(e);
    await prisma.$disconnect();
    process.exit(1);
  });
```

Run:
```bash
npx ts-node prisma/seed-therapists.ts
```

## Phase 6: Monitoring & Maintenance 📊

### Monitor Deployments

**Vercel:**
- Dashboard → SAANS Web → Deployments
- Check for errors in build logs
- Monitor Web Vitals

**Railway:**
- Dashboard → SAANS Project → Logs
- Monitor CPU/Memory usage
- Check for database connection issues

### Common Issues & Fixes

| Issue | Cause | Fix |
|-------|-------|-----|
| Backend 500 errors | No DATABASE_URL | Add PostgreSQL add-on in Railway |
| Frontend 302 redirect | SSO auth issue | Clear browser cache, try incognito |
| CORS errors | Wrong origin | Update CORS_ORIGIN in Railway vars |
| Slow API | Cold start | Keep Railway dyno warm |
| DB connection timeout | Migrations not run | Run `npx prisma migrate deploy` |
