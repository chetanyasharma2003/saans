QUICK START
================================================================================

1. Install Dependencies (Already Done):
   npm install swagger-ui-express swagger-jsdoc js-yaml

2. Start Server:
   npm run dev

3. Open Browser:
   http://localhost:5000/api-docs

4. Test Endpoint:
   - Select endpoint from list
   - Click "Try it out"
   - Click "Execute"
   - View response

5. Authenticate:
   - Get token from POST /api/auth/login
   - Click "Authorize" button
   - Paste token
   - Make requests with auto-included token
