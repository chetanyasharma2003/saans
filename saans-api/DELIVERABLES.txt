                           API ENDPOINTS (NEW)
================================================================================

PASSWORD RESET:
  POST /api/auth/forgot-password
    • Request password reset email
    • Rate limited: 5 req/min per IP
    • User enumeration protected: YES

  POST /api/auth/reset-password
    • Reset password with token
    • Rate limited: 5 req/min per IP
    • Validates: token, email, password strength

EMAIL VERIFICATION:
  GET /api/auth/verify-email
    • Verify email with token
    • No rate limit (user retry on network issues)
    • Query params: token, email

  POST /api/auth/resend-verification
    • Resend verification email
    • Rate limited: 3 req/min per IP
    • User enumeration protected: YES

UPDATED ENDPOINTS:
  POST /api/auth/register
    • Now auto-sends verification email
    • emailVerified = false until verified

EMAIL NOT SENDING:

  2. Check logs: grep "Email sending failed" logs/*.log
  3. Remove API key to test in console mode

TOKENS NOT WORKING:

  2. Verify token hasn't been modified
  3. Check rate limiting isn't blocking: grep "429" logs/*.log
